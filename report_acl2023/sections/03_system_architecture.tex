\section{System Architecture}

CredChain được thiết kế theo mô hình web application có blockchain-backed trust. Frontend React cung cấp các portal theo vai trò. TanStack Start server functions xử lý validation, truy vấn Supabase bằng service role key và đảm bảo các thao tác nhạy cảm không phụ thuộc hoàn toàn vào client. MetaMask cung cấp khóa người dùng, ký thông điệp và gửi transaction lên Sepolia.

\subsection{Frontend}

Ứng dụng có các route chính: \texttt{/login}, \texttt{/admin}, \texttt{/university}, \texttt{/student} và \texttt{/verify}. Trang login yêu cầu chọn vai trò trước khi kết nối ví. Với Admin và University, ứng dụng kiểm tra role on-chain trước khi cho vào portal.

\subsection{Server Functions và Database}

Các hàm trong \texttt{src/lib/credentials/api.functions.ts} chịu trách nhiệm lấy cấu hình registry, lưu credential, liệt kê credential theo sinh viên hoặc issuer, tạo share code và lấy presentation theo share code. Supabase có ba bảng:
\begin{itemize}[leftmargin=*]
  \item \texttt{registry\_config}: địa chỉ contract, chain id, bootstrap admin wallet.
  \item \texttt{credentials}: credential UID, metadata, chữ ký, transcript salted, anchor transaction.
  \item \texttt{presentations}: share code và JSON presentation.
\end{itemize}

\subsection{Smart Contract}

Contract Solidity gồm các hàm \texttt{addIssuer}, \texttt{removeIssuer}, \texttt{anchorCredential} và \texttt{revokeCredential}. Contract không lưu transcript hoặc dữ liệu cá nhân, chỉ lưu hash định danh và trạng thái công khai cần thiết cho verification.
