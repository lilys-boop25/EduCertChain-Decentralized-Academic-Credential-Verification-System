# CredChain ACL 2023-style LaTeX report

Import this folder or the generated zip into your LaTeX editor.

Main entry:

```text
main.tex
```

Notes:

- The report follows an ACL 2023-like two-column paper layout with `section` files instead of chapters.
- Figures are currently rendered with TikZ so the document can compile without external image exports.
- Editable draw.io source files are included in `figures/system_architecture.drawio` and `figures/methodology_flow.drawio`.
- Replace the TikZ figures with exported PDF/PNG files later if you want polished diagrams.
- The report is written in Vietnamese and uses `inputenc`, `T5` font encoding, and `babel` Vietnamese support.
